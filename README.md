### **About**
**Dex2c Plus** converts Android `.dex` bytecode into native **C++17 JNI (`.so`)** libraries, moving Java/Kotlin methods to native code for stronger protection against reverse engineering.

### **Features**
* **DEX to Native:** Translates Dalvik bytecode directly into C++17 JNI source and native shared libraries.
* **Multi-ABI Support:** Compiles native binaries for `arm64-v8a`, `armeabi-v7a`, `x86`, and `x86_64`.
* **Selective Protection:** Allows targeting specific classes or methods for native conversion.

### **How to Use**
1. **Install:** Install the **Dex2c Plus** APK and complete the initial environment setup.
2. **Select APK:** Choose your target APK from device storage or installed applications.
3. **Select Classes:** Pick the classes or methods you want to convert to native C++ JNI.
4. **Convert:** Start the process to generate and sign the protected APK.
